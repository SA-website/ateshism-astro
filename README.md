# ateshism-astro

Worldbuilding site for *The Ashen Flame*, by Alexei Sassani.

Built with [Astro](https://astro.build), deployed via Cloudflare Pages.

- `npm install` — install dependencies
- `npm run dev` — local dev server
- `npm run build` — production build to `dist/`
- `npm run astro check` — type/content validation

See `CLAUDE.md` for the editorial and technical contract governing this site.
